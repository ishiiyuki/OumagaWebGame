# 逢曲時 帳場録（おうまがとき ちょうばろく）

**彼岸旅館「逢曲時」おうまがとき ― 神楽おもてなしカードゲーム**

現世と常世の狭間にある死者の店、彼岸旅館「逢曲時（おうまがとき）」の世界観をモチーフにしたブラウザカードゲームです。  
プレイヤーは「帳場預かり」となり、全五夜にわたって現世から迷い込んだ人間（迷い人）たちを**誘魅巫女（いざなみのみこ）**の神楽でもてなし、竹林を割く坂“**黄泉平坂（よもつひらさか）**”より現世へ送り還します。

- 📜 **モチーフ世界観（公式サイト）**: [彼岸旅館「逢曲時」公式サイト](https://oumagatoki.pages.dev/#top)

## 🎮 ゲーム概要・遊び方

### 1. 宿の「評判」と神楽の「雅」を守る
旅館には2つの重要なステータスがあります。
- **🏮 評判（初期値: 3 / 最大: 5）**: 彼岸旅館『逢曲時』の威信
- **🪭 雅（初期値: 4 / 最大: 5）**: 魂を鎮める神楽とヒガン石の霊威

迷い人のおもてなし（鎮魂）に失敗し悪霊の誘惑「**ヨモツヘグイ（黄泉戸喫）**」で常世へ堕ちてしまったり、神楽が乱れたりして、**どちらか1つでも `0` になると帳場閉鎖（ゲームオーバー）**となります。  
**全五夜**の送り還しを完遂すればゲームクリアです。

### 2. 3つのお座敷と迷い人の魂鎮め
毎夜、3つのお座敷に現世から魂が離れた迷い人（客人）が訪れます。
- **大広間・神楽舞台**: 🪭【舞踊】+1（芸者・ハルカ配置時 +2 / 帳場頭・にゃる配置時 +3）
- **竹林望む離れ座敷**: 💬【話術】+1（猫の誘魅・まりん配置時 +2 / 帳場頭・にゃる配置時 +3）
- **彼岸月見の宴席**: 🍶【座興】+1（獄門鬼女中・ならく配置時 +2 / 帳場頭・にゃる配置時 +3）

客人が求める神楽（**💬【話術】・🪭【舞踊】・🍶【座興】**）の要求値を確認し、条件を満たす誘魅巫女をお座敷へ配置（ドラッグ＆ドロップまたはクリック選択）しましょう。要求値を満たせば【**神楽成就**】となり、掛け合いカットインとともに黄泉平坂より現世へ送り還せます。

### 3. 誘魅巫女の山札と「帳場の呼び鈴」
全8名の誘魅（いざなみ）山札から、毎夜ランダムで**4名**が手札に配られます。
- **🔔 呼び鈴（手札入替 / 雅-1）**: 手札と客人の要求が合わない時は、1夜に1回だけ「雅」を1消費して、未配置の手札を山札から引き直すことができます。

### 4. 登場する誘魅巫女（全8名）

## 🚀 起動・動作方法

ビルドツールや外部ライブラリ（フレームワーク）に依存しないバニラHTML/CSS/JavaScript構成のため、そのままブラウザで開くかローカルサーバー経由で動作します。

### 1. 直接ブラウザで開く場合
`index.html` をそのままモダンブラウザ（Google Chrome / Microsoft Edge / Firefox / Safari 等）で開いてプレイできます。

### 2. ローカルサーバーで起動する場合（推奨）
VS Code の Live Server 拡張機能や、Python・Node.js などの簡易HTTPサーバーを使って起動できます。

```bash
# Python 3 を使用する場合
python -m http.server 8000

# Node.js (npx serve) を使用する場合
npx serve .
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
